# 更新履歴

## v0.0.9

- 次の1食を表示するホーム画面ウィジェットを追加。
- 日付・朝昼夕・献立をカードに表示し、時間帯自体は非表示。
- 朝食デフォルト、日別A/B・欠食を反映。サイズ変更、手動更新、対象日の献立を開く操作に対応。
- 食事の終了を目安に次へ切り替え、保存データ・公開保留・未取得を区別。
- 設定からホーム画面へのウィジェット追加を案内。

## v0.0.8

- 朝・昼・夕それぞれの通知オン／オフと時刻設定を追加。
- 朝食通知に朝食デフォルトを反映。通知を試す機能、再起動後の予約復元に対応。
- Kanji Alcohol（酒）を含むMaterial Symbols 28種類から通知アイコンを選択可能に。
- 献立の統計ページを追加。料理・組み合わせの登場ランキング、検索、登場日の一覧、月別・曜日別、栄養分布、個人の選択・欠食を表示。
- 統計の期間・朝昼夕による絞り込みに対応。

## v0.0.7

- 画像／文字の献立表示切り替え、日別の朝昼夕、A/B・共通料理・案内の表示を追加。
- A/B選択・欠食の端末内記録と、朝食デフォルト設定を追加。
- 週間・累計の栄養レポート、日別グラフ、選択内容とA/B試算の切り替えを追加。
- 相談用テキスト／JSONの書き出し、個人記録のバックアップ・復元を追加。
- 生JSON・欠食記録の確認、過去の献立の表示方法選択、設定やポップアップの表示を改善。
- 運営者情報と問い合わせ先を更新。
